# Brasão do relatório

`brasao-republica.png` é a versão em preto e branco das Armas Nacionais,
utilizada no cabeçalho do RVN, conforme a referência visual enviada.

- Fonte: [Wikimedia Commons — Brasao-em-preto-em-branco.jpg](https://commons.wikimedia.org/wiki/File:Brasao-em-preto-em-branco.jpg).
- A miniatura de 120 × 120 px foi convertida para PNG, removendo 2 px de borda externa em cada lado. O desenho não foi alterado.
- Exibição: 1,5 × 1,5 cm, centralizada acima das linhas institucionais.

O arquivo é servido localmente, sem depender de Google Drive ou de outro site
para aparecer na prévia e na impressão/PDF. O tamanho foi aproximado a partir
da imagem de referência, não medido no PDF original.
